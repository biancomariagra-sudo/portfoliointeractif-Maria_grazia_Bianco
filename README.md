# Portfolio professionnel — Maria Grazia Bianco

Site statique prêt pour GitHub Pages.

## Publication avec GitHub Pages
1. Créer un dépôt GitHub public, par exemple `portfolio-maria-grazia-bianco`.
2. Importer **le contenu de ce dossier** à la racine du dépôt (`index.html`, le PDF du CV, la photo, le dossier `assets`, `.nojekyll`).
3. Dans GitHub : **Settings → Pages**.
4. Dans **Build and deployment**, choisir **Deploy from a branch**.
5. Sélectionner **main** et **/(root)**, puis **Save**.
6. Attendre la publication et ouvrir l'URL fournie par GitHub Pages.

Tous les liens locaux utilisent des chemins relatifs et sont compatibles avec GitHub Pages.
